Editor Support
==============

Visual Studio Code
------------------

The official `Animal Language`_ VS Code extension adds everything you need for day-to-day development:

- Syntax highlighting powered by TextMate grammar rules
- File and icon themes for ``.anml`` sources
- Comment toggling and bracket matching tailored to the language

Install it directly from the Marketplace:

.. code-block:: text

   ext install klus3kk.animal

Or search for **Animal Language** inside the Extensions side bar. Once installed the extension automatically associates ``.anml`` files with the language. If you have multiple icon packs enabled you can switch back to the default icons—only ``.anml`` files are themed by the extension.
