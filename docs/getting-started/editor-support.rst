Editor Support
==============

Visual Studio Code
------------------

The official `Animal Language`_ VS Code extension adds some useful features to the editor when working with ``.anml`` files:

- Syntax highlighting powered by TextMate grammar rules
- File and icon themes for ``.anml`` sources
- Comment toggling and bracket matching tailored to the language

Install it directly from the Marketplace:

.. code-block:: text

   ext install klus3kk.animal

Or search for **Animal Language** inside the Extensions side bar. Once installed the extension automatically associates ``.anml`` files with the language.
